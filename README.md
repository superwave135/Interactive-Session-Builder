What the product actually does:
It empowers a user to assemble reusable interactive components into a structured session experience, save it as a single portable web file, and share it with participants who can use it live — with no app, no login, no internet.


"Interactive" - signals it's not a static document — it has polls, timers, tabs, live Q&A

"Session" - works universally across every vertical we identified — tutors, coaches, trainers, church leaders, therapists, sales managers

"Builder" - communicates the drag-and-drop, modular, Lego-blocks mechanic
